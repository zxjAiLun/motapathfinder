## 问题

PR-5.19k 已关闭。真实 depth-2 generic make-viable：

```text
not-satisfied / 50 expansions / budget-exhausted
```

但其 50 次搜索内部已经发现了 42 个 positive survival edges，best chain 也可逐边分解。

当前实现是：

```text
整个 50-expansion 失败
→ 只保存 attribution
→ 不产生任何 prerequisite
```

5.19l 要把它变成：

```text
失败，但发现离散、合法、terminal-relevant opportunity O
→ compile survival-opportunity-prerequisite
→ 复用已经计入 total work 的 witness chain
→ strict replay
→ opportunity consumed
→ materialize
→ preserve parent continuation
```

## 冻结选择规则

```text
1. only depth>0 lethal generic child failed connector evidence
2. only positive named primitive opportunity
3. first discovered by BFS discovery order
4. semantic target signature only stable tie-break
5. NO ranking by deltaSurvivalMargin / deltaHP / sourceCount
```

original generic attempt 保持失败，不得改成 satisfied。

## Completion predicate

> named battle opportunity O 已被合法消费/取得。

第一版只支持 battle opportunity consumed；使用 canonical tile/mutation/option-state 判断，不通过 survivalMargin 反推。

## Witness

对选中 opportunity 保留：

```text
witnessChain = chainBefore + action
```

必须：

```text
verifyConnectorChain(lethalSourceState, witnessChain) valid
AND completionPredicate(finalState) true
```

之后才 materialize。观测 evidence 不能直接驱动 solver。

## 真实 frozen mechanism gate

预算不变：

```text
total=1000 / maxCalls=8 / perCall=50 / lazyDrain unchanged
```

先复现：

```text
attack-blocked → damageable → lethal
→ generic make-viable 50-exp fail
```

然后：

```text
positive opportunity edges exist
→ compile exactly one discrete opportunity
→ witness strict replay PASS
→ opportunity consumed
→ materialized exact state
→ parent continuation created/preserved
```

更强 positive：

```text
materialize 后 survivalMargin 改善
```

但 margin 不是 satisfaction gate。
