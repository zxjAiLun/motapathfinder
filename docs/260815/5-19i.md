## 问题

```text

  created at expansion 400

```

5.19e 给 hierarchy 分配了 connector call priority，但没有给 continuation 依赖的 canonical anchor 相应 strategic expansion opportunity。两套调度脱节。

## 本轮机制

```text
stage prerequisite satisfied
→ continuation created
→ waiting-for-parent-floor
→ anchor canonical node 尚未 expanded
→ enqueue one-shot anchor expansion request
```

主循环选 strategic node 时：

```text
pending active-continuation anchor
且 anchor 尚未 expanded
→ 选择该 anchor 作为下一次普通 strategic expansion

否则
→ agenda.pop(expanded)
```

只改变“下一个由谁使用 strategic expansion slot”，不增加 slot。

## 生命周期合同

```text
enableContinuationAnchorExpansionScheduling = false
```

默认关闭，5.19f / 5.19h frozen 数字不漂。

pending request 必须满足：

```text
continuation still active
AND continuation waiting-for-parent-floor
AND anchor exists
AND anchor NOT in expanded
```

最多消费一次。

- 普通 agenda 先选中 anchor → request stale 丢弃，不 re-expand
- continuation completed/released → request cancelled/stale，不抢 slot
