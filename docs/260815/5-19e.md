## 问题

PR-5.19d 已 `MECHANISM POSITIVE / NOT PROMOTED` + `APPROVED / CLOSED`。当前 frozen evidence 表明：

```text
P1 satisfied
→ continuation resume
→ P2 = cb70ef61 已编译
→ statusReason = call-cap-exhausted
→ P2 一次 call 都没获得
```

原因不是 attribution 或 connector 能力，而是：

```text
固定 8-call budget 被第一层 sibling attempts 全部耗尽；
hierarchy deeper child 没有获得执行机会。
```

## 本轮目标

在同样预算下改变 call 分配顺序：

```text
普通 sibling attempt
↓
某次 P(B) SATISFIED
↓
激活 active hierarchy priority
↓
普通新 sibling connector attempt 暂停抢占 call slot
↓
strategic search 继续推进
↓
lineage-safe descendant 返回 parent floor
↓
resume
↓
编译出 deeper prerequisite
↓
deeper prerequisite 获得下一个可用 call
↓
deeper feedback 后释放 priority
```

不是 `8 → 9/16`，也不是固定 `6+2` 切分，更不是永久预留第 8 个 call。

## 冻结范围

- `maxTotalSearchExpansions = 1000`、`connectorMaxCalls = 8`、`connectorMaxExpansions = 50`、`lazyDrainEvery` 均不调整。
- hierarchy priority 由真实 `P(B) SATISFIED` 动态激活；没有 success 时不预留 call。
- priority 只暂停新的 sibling connector call，不暂停 strategic expansion、lazy drain、continuation waiting/resume。
- release 条件：
  1. deeper prerequisite 得到一次真实 connector feedback
  2. parent 已 completable/reachable，无下一 prerequisite
  3. continuation blocked/unsupported
  4. 搜索整体 budget exhaustion
- 不新增 stage-specific connector。
- 不新增 budget、不读 known route、不碰 DP key / dominance / replay semantics。
- D3 仍 NOT AUTHORIZED。
