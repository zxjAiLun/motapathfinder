## 初始设计

第一版只支持 `battle-unsurvivable`，不支持 missing-key / closed-door / event-condition / changeFloor。

Prerequisite schema：

```text
kind: battle-access-prerequisite
parentDependency: T
boundary:
  floorId
  x
  y
  enemyId
completionPredicate(state):
  battle resolver supported
  AND
  battle damage != null
  AND
  battle damage < current hero HP
provenance:
  sourceAttemptId
  sourceExactStateFingerprint
  structural path evidence
  firstObservedUnresolvedBoundary
```

connector 继续使用 completionPredicate-only primitive search；成功条件是 P(B) 满足，不是 survivabilityScore / battleMargin 最大。

## 范围与非目标

### 本轮范围

- `compileBattleAccessPrerequisite`：从 T + structural attribution 的 first boundary 编译 P(B)。
- 新 lazy kind `battle-access-prerequisite-choice`，与现有 shared total-work hard cap 集成。
- 记录 mechanism metrics：compiled / satisfied / stateCreated / globalBlockerAdvanced，以及 satisfied 前后的 battle classification 与 structural access。
- same-total-work frozen A/B：strategic-only 1000 vs battle-access candidate 1000。
- 若 goal found，full route reconstruction + strict replay。

### 不在本轮 / 未授权

- 不一次编译 `[B1, B2, B3]` 整条 structural path；只取 firstObservedUnresolvedBoundary。
- 不新增 missing-key/door/event/changeFloor prerequisite。
- 不读 known route、人工坐标名单、人工 event order 或资源阈值。
- 不改 agenda、dominance、DP key、production segment solver。
- 不增 connector per-call budget、maxCalls、total work，不调 lazyDrainEvery 制造效果。
- 不进入 D3；D3 = NOT AUTHORIZED。

## 合同与不变量

- completionPredicate 只判定指定 exact battle 当前是否 viable；不得使用 scalar margin 最大化。
- satisfied 后必须 strict replay chain，并重新记录当前 state 的 structural attribution。
- 不能预测 B 之后的状态；下一层 prerequisite 必须来自新 state 的新 attribution。
- 5.19a observer 保持 observation-only，不改搜索。
- total-search-work = strategic + 所有 connector work，strict hard cap 保持。

## 验收与拒绝门

| Mechanism gate | frozen A/B | 至少一次 P(B) satisfied + 新 exact state，或 re-attribution 后 first boundary 改变 / minStructuralCrossings 减少 / T 可完成 | 有新增发现能力 |

Mechanism gate 与 promotion gate 分开：P(B) satisfied 但 best 仍 -903 时，机制可判正结果，promotion 不授予。

## 结果与决定

当前状态：`VERIFIED`（implementation + CI）；frozen real A/B 的 mechanism gate 与 promotion gate 均未通过。

在 50-expansion per-call、8 calls、same total work 约束下，battle-access prerequisite connector 没有使任何 exact battle 变为 viable-at-current-state，因此没有产生新 exact state，也没有推进 terminal blocker。这不是 scheduler artifact；5.19a attribution 的 first boundary 是真实的，但 5.19b 当前 primitive search 未能完成该 prerequisite。
