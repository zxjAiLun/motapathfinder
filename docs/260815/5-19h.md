## 问题

PR-5.19g 的 negative evidence 只能拒绝 historical tree-descendant hypothesis：

```text
eligibleHistoricalDescendantsAtCreation = 0
futureDescendantsObservedAfterCreation = 0
```

它还不能证明：

```text
anchor S 没有合法 transition 回 MT5
```

因为 strategic 主循环对已存在 exact state 只做：

```text
exactMerged++
continue
```

不会把 `S → canonical X` 记录成 lineage edge。所以 single-parent tree 可能把真实合法 transition 抹掉。
