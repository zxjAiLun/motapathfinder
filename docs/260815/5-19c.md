## 问题与已有证据

PR-5.19b 已正式关闭为 `MECHANISM POSITIVE / NOT PROMOTED`。当前已知：

```text

  satisfied 2 / stateCreated 1 / globalBlockerAdvanced 0

```

但 `battle-unsurvivable` 仍是一个 umbrella。远端 attempt telemetry 已显示两类：

```text
damage = null    → 更接近 attack-blocked
damage >= HP     → lethal
```

成功 witness 是 `skeletonPresbyter@MT5:3,10`：lethal → viable。多轮 `evilHero` 尝试 damage=null，更接近 attack-blocked。

当前 compile 的 `capability: "survival"` 对所有 battle-unsurvivable 不够准确。5.19c 需要先归因，不增加新的搜索能力。

## 初始设计

新增通用分析：

```text
analyzeBattleViabilityBlocker(simulator, state, boundary)

output:
  stage: unsupported | attack-blocked | lethal | viable
  attackMargin
  damage
  heroHp
  survivalMargin
  enemyDef
```

不直接复用 terminal-only 命名，因为 boundary 是任意 access battle。

对 5.19b 的 8 个 attempt 输出：

```text
attemptId
sourceFingerprint
boundary
beforeStage
afterStage（成功 attempt）
```

对 successful attempt 增加：

```text
chainSummary
resourceDelta

final:
  floorId / HP / ATK / DEF / MDEF

battle before/after:
  stage
  attackMargin
  survivalMargin

structuralAfter:
  floorScoped
  minStructuralBoundaryCrossings
  firstObservedUnresolvedBoundary
  unavailableReason
```
