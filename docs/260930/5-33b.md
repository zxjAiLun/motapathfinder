## Initial design (freeze before implementation)

1. Keep canonical DP, dominance, agenda and weights unchanged. Work in shared-solver; tower runtime is a read-only semantic reference.
2. Share action/script support classification between enumeration and execution. Unknown script bodies must fail closed, including nested common events; only explicitly audited presentation scripts may be no-ops. Recognize the required visited-history reset without evaluating arbitrary JavaScript.
3. Load named common events through the project loader and execute supported calls with explicit recursion/shape guards. Match runtime argument/context behavior for the supported subset; reject unimplemented forms rather than guessing.
4. Reuse the existing equipment model for unload effects, including inventory, flat/percentage modifiers and slot semantics. Implement follower removal and visited-history changes in the existing canonical state/snapshot representation. Add negative and round-trip controls.
5. Rebuild a diagnostic route from the original trial initial state and the saved action sequence. Preserve provenance and prior evidence; write new results into `shared-solver/routes/generated/260930-pr533b/`. No witness or derived checkpoint is a production search input.
6. Verify internal strict replay and real-browser replay all the way through Boss settlement/JC19. Compare state, inventory, flags, visited history, equipment/followers, score and gross green-key spend (≤1), not only enemy removal or remaining HP.
7. Run targeted local checks and the normal fast layer; use GitHub clean-environment qualification for the full evidence suite, not a duplicated full local run. Repair the specifically documented stale generated-fixture checks if they block the release, without sweeping unrelated artifacts into publication.
8. After semantic/replay/qualification gates, package a frozen release and deploy to server1 only, under a new application-specific directory with a fresh journal. Use an unused loopback port and an authenticated SSH tunnel, not a public unauthenticated UI.
