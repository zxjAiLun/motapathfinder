## 问题与已有证据

PR-5.24c 终审（F1/F2 Diagnostic）确认：在基于 input-wave 划分 hypothesis 的结构下，真实 MT1→MT2 回滚因 `inputFrontier.length = 1` 仅生成单个 ticket `h-d1w0`，且该 ticket 下 anchor re-expand 后的整个 merged 前沿被打包成单一 replay frontier 试探，既无法区分各保留资源历史的下游推进效果，也使得单一候选消耗 probe 阻断了其他候选的下游试探。

然而，求解器早已具备完备的通用资源多样性（Resource Diversity）保留机制（Pareto protection、resource novelty、skyline roles）。即：
> **Canonical DP 已经努力保存了不同资源历史，但 scheduler 的 hypothesis 边界还停留在“从哪个输入状态开始 rollback”。**

PR-5.24d 消除这一结构失调：将“不同输入波次间的公平调度”下沉推进为“不同修复输出历史间的公平调度”。

## 范围与非目标

本轮范围（`segment-dp.js` 为主）：
- 共享单次 anchor 重新扩展（Shared Anchor Expansion）：每个 input wave 仅执行一次 anchor 扩展，产生 `expandedAnchor.merged = [A, B, C, ...]`。
- 假说粒度下沉：新增 `buildRepairedHistoryHypotheses` 纯 helper，将 `expandedAnchor.merged` 中的每个保留候选拆分为独立的 repaired-history hypothesis（`replayFrontier = [candidate]`）。
- 假说标识与遥测：`hypothesisId`（包含 parentWave 与 candidate identity/rank）、`parentWaveId`、`anchorOutputCandidateId`、`anchorOutputRank`。
- 首轮公平性屏障（First-probe fairness barrier）：同一 depth 下所有 repaired-history hypotheses 完成首轮 probe（`probeIndex === 1`）之前，绝不发放任何第二轮延续授权（`second grant`）。
- 独立进度度量：
  - `historicalAnchorProgress`：原历史 `anchor.merged` 的全局最优投影；
  - `repairedAnchorProgress`：该假说对应的**单一** repaired candidate 投影（不再使用全前沿 best）；
  - `replayBestProgress`：该假说下游 replay 产生的最优投影；
  - `goalProgressAfter = bestOfProgressProjections(repairedAnchorProgress, replayBestProgress)`。
- 门禁体系：G23 A–F（覆盖单输入拆分、首轮公平性、独立进度区分、延续胜出、无枚举膨胀、单候选等价性）。

非目标：
- 不扩大 DP 枚举或搜索宽度（`candidateLimit`、`goalSkylineLimit`、`backtrackCandidateLimit` 严格保持不变）。
- 不修改进度度量比较器、不新增进度字段、不加权重。
- 不提前用 progress 过滤删除 output histories（repaired == historical 依然获得 first probe）。
- 不调整 30s/50k 算法预算、不做 Linux qualification、不做 failure-intent 调优。

## 初始设计

1. **共享 Anchor 扩展**：
   在 `tryAdaptiveCheckpointRepair` 中，当某个 anchor wave 开始执行时，在父 wave 预算下执行一次 `runSegmentAgainstFrontier(...)`。
   若 anchor 扩展产生 $K$ 个保留候选（$K \le \text{backtrackCandidateLimit}$），则将其映射为 $K$ 个 child hypotheses。
2. **Replay 试探解耦**：
   每个 child hypothesis 拥有独立的 `replayFrontier = [candidate]`，并在其绑定的局部 probe 预算下独立执行下游 replay。
3. **进度与授权分离**：
   每个 child hypothesis 独立计算 `progressClass` 与 `continuationEligible`。只有首轮所有 child hypotheses 均完成 first probe 后，才依据离散进度决策是否给予 second grant。
