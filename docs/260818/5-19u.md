## 本轮范围（observation-only）

对每个 root attempt 记录 charge 前就存在的语义向量：

```text
callOrdinal / attemptId（身份显示）
sourceNodeId / sourceDepth / sourceFloor
prerequisiteKind / stageGoal
parentDependencyKind / parentDependencyCapability
reachableAtCompileTime
boundary classification（enemyId/x/y 仅身份显示，不作为区分特征）
battle stage before connector / attackMargin / damage / survivalMargin
source terminal-blocker projection（progressScore）
compiledCandidateRank / compiledCandidateCount
queue/selection context（queuedCount、callsRemainingAfter、firstHierarchyActivationOccurred）
```

search-end 只绑定 hindsight label：

```text
directSatisfied
productive
```

禁止把以下任何一项作为 pre-charge discriminator：

```text
connector satisfied
connector expansions actually used
productive
future continuation
O1/O2/O3/O4 outcome
attemptId / enemyId / 坐标（只能身份显示）
```

## 分类合同

```text
U1 = SEMANTICALLY SEPARABLE
     ∃ 单个通用 semantic feature f：f(#5) != f(#i) 对所有 failed root i
U2 = FEATURE COLLISION
     #5 的冻结 semantic vector 与至少一个 failed root 完全相同
U3 = ONLY TEMPORALLY SEPARABLE
     semantic vectors 全同，只有 ordinal/expansion 能区分
U4 = EVIDENCE INCOMPLETE
```

组合可区分（每个 failed root 都与 #5 不同、但无单一 feature 全分离）如实报告为 `U1-COMBINATION-ONLY`，不冒充 U1。

## Verified Result

```text
U1 = SEMANTICALLY SEPARABLE

productive root #5 在 connector 执行前已有多个可泛化的 semantic 特征与
#1-#4 全部分离：

  attackMargin:  +377（唯一正值，可造成伤害）
                 vs #1-#3 = -273、#4 = -173（attack-blocked / 全负）
  damage:        39321 vs null / null / null / 1978814
  survivalMargin: -26036 vs null / null / null / -1741823
  sourceDepth:   1 vs 0 / 2 / 4 / 5

其中 attackMargin 是最有语义意义的 separator：
#5 是唯一在 charge 前就能“伤害目标”的 root attempt（battle stage 虽为
lethal，但 attack 已通过，damage 有界 39321）；#1-#3 全部 attack-blocked，
#4 虽 lethal 但 attackMargin=-173 且 damage 高达 1978814。
```

结论（observation，非 policy）：

```text
存在 non-oracle、pre-charge、可泛化的 semantic signal 区分 #5 与 #1-#4
（attackMargin 正负/数值、damage 规模等）。

这为下一轮设计 fixed-8 root selection A/B 提供了合法依据——
按 pre-charge semantic（如 attack viability / expected damage 规模）
把 #5 提前到前 4 个 call 的讨论可以开始。

仍不授权：任何 selection policy 实现、static reserve、maxCalls 8→9、
bounded reservation、allocation 改动。
```
