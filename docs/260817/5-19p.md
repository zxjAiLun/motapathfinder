## Compatibility and replay contract

Selected prefix is:

```text
selectedPrefixEdges = O2.witnessEdges.concat(O3.residualSuffix)
selectedPrefixPostExactStateKey = O3.paid postExactStateKey
```

Candidate is O3-compatible only when:

```text
selectedPrefixEdges is an exact prefix of candidate.witnessEdges
```

For compatible candidates, replay only:

```text
candidate.witnessEdges.slice(selectedPrefixEdges.length)
```

from the O3 materialized post state with expected candidate `postExactStateKey`.

The prior O2-level `suffixReplayValid` is not reused as authority. This round performs a new diagnostic strict replay from O3 state.
