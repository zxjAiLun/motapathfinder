## Compatibility contracts

### Prefix-compatible

candidate O3 的完整 witness chain 必须满足：

```text
O2.witnessEdges is an exact prefix of O3.witnessEdges
```

只有此时，candidate 的 residual suffix 才能从 O2 post state 取得路径来源。

### Exact-state reroot-compatible

较宽的诊断类别允许 candidate path 中存在：

```text
edge.preExactStateKey == O2.postExactStateKey
```

然后从该 exact-state edge 截取 suffix。该类别同样必须 strict replay；exact key 匹配本身不构成 recovery authorization。

### Branch safety

O2 与 O3 若来自同一 source 但分属不同 BFS branch，不得认定为兼容；不能跨 branch transfer witness。
