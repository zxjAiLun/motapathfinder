## 初始设计

仅允许以下来源链：

```text
same failed connector attempt
→ complete retained snapshot
→ selected first-positive O2 witness
→ O3 full witness has O2 witnessEdges as exact prefix
→ residual suffix strict replay from O2 materialized post state
→ discrete O3 completion
→ canonical materialization
→ preserve parent continuation
```

这不是新的 connector result，也不是新的 search。residual suffix 的 primitive edges 已由原 connector call 支付；本轮只重新验证并消费该 evidence。

## 本轮范围

- 仅使用同一 `originFailedAttemptId` 的 retained witness snapshot。
- 仅使用 `snapshot.captureComplete === true` 的 graph。
- 仅使用 later named positive battle opportunity。
- 仅使用 selected O2 `witnessEdges` 为 O3 `witnessEdges` exact prefix 的 candidate。
- 按 snapshot `discoveryOrdinal` ascending 选择第一个 candidate。
- 对 O2 materialized exact state 与 residual suffix 再次执行 `verifyConnectorChain()`。
- replay PASS 且 O3 discrete completion true 后，调用现有 canonical materialization。
- 只消费一个 O3，然后回到现有 parent continuation hierarchy。

## 非目标与未授权

- exact-state reroot recovery 本轮明确未授权，即使 observation 能够识别 reroot candidate。

- 不增加 connector call、connector search expansion、total work、maxCalls、perCall 或 lazy drain。
- 不调整 call allocation、hierarchy priority、anchor scheduling 或任何 scheduler 行为。
- 不改变 DP key、dominance、selection、replay semantics 或 generic predicate。
- 不使用 scalar survivalMargin/HP/damage ranking。
- 不使用 known route、历史 best chain、手写 candidate target 或坐标。
- D3 仍 `NOT AUTHORIZED`。

## Selection and replay contract

Selection policy is frozen as:

```text
first-prefix-compatible-replay-valid-residual-by-bfs-discovery
```

`deltaSurvivalMargin > 0` only discovers candidates. It is not the completion predicate and cannot rank candidates.

For the selected O3:

```text
O2.witnessEdges is an exact prefix of O3.witnessEdges
O3 suffix = O3.witnessEdges.slice(O2.witnessEdges.length)
```

Recovery must then execute:

```text
verifyConnectorChain(
  simulator,
  O2.materializedFinalState,
  O3 residual suffix,
  expectedPostExactStateKey = O3 paid postExactStateKey
)
```

Only when both conditions hold may it materialize:

```text
replay.valid == true
AND
O3 discrete completion predicate == true
```

The prior observation field `suffixReplayValid=true` is evidence only and cannot replace this replay.

## Fail-closed guards

No residual recovery is allowed when any condition fails:

```text
captureComplete == false
selected O2 post exact state mismatch
O2 witness is not an exact prefix of candidate witness
candidate is reroot-only
candidate is branch-incompatible
residual strict replay fails
O3 discrete completion is false
```

No recovery path may materialize an O3 state from a partial snapshot or an observation-only result.
