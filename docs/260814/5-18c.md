PR-5.18b 已将 primitive variants 聚合为 choice-level `StrategicTransition`，并建立 reachable-POI、机会成本、不可逆成本、lineage novelty 和 terminal blocker progress。

终局 blueKing 在起点为 `attack-blocked`，ATK 缺口 `-1223`；最好 witness 改善到 `-923`，1000 expansions 内有 1025 个 transition 改善 blocker progress，但没有生成终局动作。因此问题不是“完全看不到局部收益”，而是直接 primitive frontier 尚未把这些收益连接成可达终局的合法链。

仍有三类显式未完成工作：

- 407 个非 canonical exact post 只记录未展开；
- 无法由当前 primitive action 直接执行的战略 choice 没有局部连接器；
- floorFly 直接全展开会产生 travel-variant explosion，当前被延期。

## 初始设计

战略层只决定“值得尝试哪个 choice”，局部 DP 只回答“能否从当前 exact state 合法到达并执行它”。局部 DP 不得决定全局路线目标。

计划数据流：

```text
strategic choice
    ↓ direct primitive action available?
yes → aggregate/apply exact posts
no  → bounded local connector
          ↓
      primitive decision chain + exact post states
          ↓
choice-level lazy resolution
    ↓
strategic frontier
```

travel variants、deferred exact posts 和 floorFly 都以同一惰性接口解析：首次只调度 choice；只有该 choice 被抽取或直接分支不足时，才支付连接和 variant 展开成本。

## 合同与不变量

- 输入仍为 tower、route-free current state 和 terminal goal。
- connector 必须从调用时 exact state 开始，返回可重放 primitive decisions 和 exact post state。
- direct path 与 connector path 到达相同 exact post 时允许合并；不同 exact post 不得静默丢弃。
- deferred work 必须处于 `queued/resolved/rejected-with-reason` 之一，不能只增加计数后消失。
- floorFly 的 choice identity 与 travel variant identity 保持分离。
- 启发式只决定何时解析，不得把未解析分支报告为已穷尽。
- `searchComplete=true` 要求 goal found，或 active frontier、deferred work 和 connector work 全部穷尽。
- 找到目标后必须重建 primitive decision chain、构建 route record 并 strict replay exact final state。
- generated outputs 写入 ignored/generated 目录；不提交一次性 summary 脚本。

## 验收与拒绝门

| Gate | Evidence | Pass condition | Meaning |
| --- | --- | --- | --- |
| Connector legality | synthetic + real local control | 每条 connector chain 可从 exact input 严格执行到 recorded exact post | connector correctness |
| Lazy exact-post recovery | alias/deferred controls | 非 canonical post 可按需进入 frontier，且没有数组顺序依赖 | 关闭 5.18b deferred gap |
| Lazy floorFly | variant-explosion control | choice 级占槽，只有按需解析 variant；不再在根节点生成上千 frontier entries | 控制展开成本 |
| Completeness accounting | outcome contract | unresolved work 时 `searchComplete=false`；穷尽声明包含所有 lazy queues | 诊断可信 |
| D2 fixed-budget A/B | 1000-expansion probe | 公开四元组、choices/variants、connector calls、deferred/resolved、frontier、wall | 判断方向，不自动等于 closure |
| Goal closure | route record + strict replay | 若 goal found，完整 primitive chain 与 final exact state 一致 | D2 closure 的必要条件 |

若 connector 只增加 wall/branches、没有使 terminal action 或依赖链更接近可执行，结果仍是有效 `VERIFIED / NOT_PROMOTED`，而不是基础设施失败。
