## 1. 背景与前序裁定

在 `298d78b`（TS13 Shadow Audit Repair 1b）中，我们正式关闭了“直接删除 mutation 历史 + 未来动作签名”的粗化抽象候选（在 3 个真实 TS13 durable fixture 上均观测到 80~114 个违反无后效性的后继反例，`correctnessGateAllTransitions = false`）。同时，基于 2,664 对相同生产 DP Key 的严格支配转移检查确立了 `no-counterexample-observed`，证明生产 DP Key 现有语义是健全的。

审查裁定：
1. **Part A 候选抽象正式永久拒绝**：不继续在这个有损方案上打特例补丁。
2. **研究升级为 5.28a**：转向 **Fail-Closed Mutation Liveness**（突变活性判定）。
   - 核心原则：**证明死亡才可删除，无法证明死亡一律保留（Fail-Closed）**。
   - 目标：量化在没有启发式猜测、不编码任何楼层/怪物特例的前提下，到底有多少 mutation 能够被数学级证明“在任何未来 continuation 中都不可能再次被观察”。
   - 门禁：硬性要求 `0 counterexamples`；实用性只测量并报告，不因 collapse ≈ 0 判失败。若无 mutation 可被安全证明死亡，也属于有效的科学负结果（Valid Negative Result），直接停步汇报。

## 2. 机制设计：数学级 Fail-Closed 活性谓词 (`lib/mutation-liveness.js`)

以 `state.floorStates[floorId].removed` 与 `.replaced` 为对象，追踪它们在 `getTileDefinitionAt`、走行动作枚举、区域可达性、跨楼层转移与到达事件中的未来潜在影响。

### 规则 1：楼层级未来不可达判定（`floor_unreachable_in_future`）
- 在 `project.floorsById` 与 `config.allowedFloors` 约束下，从当前状态 `state.floorId` 出发，沿 `changeFloor`（楼梯、传送点）与 `canUseFloorFly`（如果持有有效飞羽道具）构建有向楼层可达图。
- 计算从当前楼层出发的前向可达楼层传递闭包 $ReachFloors(state.floorId)$。
- **定理 1**：若楼层 $F \notin ReachFloors(state.floorId)$，则从当前状态出发的任何合法路线都绝不可能踏足或观察到楼层 $F$。
- **动作**：楼层 $F$ 上的所有 mutation 判定为 **PROVABLY DEAD**。

### 规则 2：单楼层拓扑物理隔离判定（`topologically_isolated_from_all_entry_points`）
- 对于任一可达楼层 $F \in ReachFloors$：
  - 提取所有可能的物理入场坐标集合 $E(F)$（包括所有入站 `changeFloor` 的着陆坐标；若 $F$ 为当前楼层，亦包含主角当前位置）。
  - 在楼层 $F$ 上执行泛洪可达性上近似：
    - 永久不可破坏障碍（蓝墙、永久岩石等）视为绝对不可通行；
    - 带有受保护道具成本的门（零绿钥匙约束下的绿门）视为**永久不可通行**；
    - 其余所有地块（怪物、道具、普通非保护门）均保守视为**可通行（上近似）**。
- **定理 2**：若楼层 $F$ 上的某突变坐标 $(x, y)$ 无法从 $E(F)$ 中的任何入口通过上述上近似路径连通，则任何合法路线都绝不可能移动至其邻接位或踏上该点。
- **动作**：坐标 $(x, y)$ 处的 mutation 判定为 **PROVABLY DEAD**。

### 规则 3：无法证明者一律保活（Fail-Closed Fallback）
- 只要突变位于未来可达楼层且处于连通通道内，无论其当前离主角多远，一律判定为 **LIVE**，严格保留在生产 DP Key 中。

## 4. 科学结论与证据分析

1. **Correctness Gate 100% 通过（零违例）**：
   - 全程转移违例数恒为 **0**（`totalViolations = 0`），没有制造任何破坏最优子结构的假性等价。
2. **Fail-Closed 活性证实了生产 DP Key 的保守必要性**：
   - 在三个持久化语料的 **66,077 次突变检查** 中，死突变数量严格为 **0**。
   - **根本原因**：
     在双向楼梯连通塔（TS13 $\leftrightarrow$ TS12 $\leftrightarrow$ TS11）中，所有已被访问过的历史楼层均在可达图内；且由于所有已击杀怪物和已吃药水均分布在主干道通道上，其地块全部在上近似连通区内部。
   - 一旦主角倒退回访上一层，任何在连通区内的“已拾取 vs 未拾取”差异都会立刻改变地块通行阻挡与可用动作。
   - 这从数学逻辑上完全解释了为什么此前粗暴丢弃 mutation 会产生数百个后继反例——**因为在开放连通图下，通道上的突变本质上全都是 LIVE 的！**
3. **成果定性**：
   本轮实验严格遵守预声明规则：不扩大 heuristic，不硬编码任何特例，如实确认了在纯物理拓扑与楼层连通性下，通道突变无法被无损证明死亡。这是一个**严谨、确定性的有效负结果（Valid Negative Result）**。
