## Resource signal V1 (frozen)

```text
combatProgress(transition) =
  deltaAtk > 0 OR deltaDef > 0 OR deltaMdef > 0
  OR deltaHpmax > 0 OR deltaLv > 0
  OR equipment changed (combat-state change)
```

```ini
EXP_ONLY_PROMOTION = FALSE
  almost every battle grants EXP; EXP-based admission would re-flood the
  high-priority class with ordinary battles. cp#8 carries ATK +5, so the
  signal does not need EXP.
IDENTITY_USED = FALSE   (no enemy ID, no coordinate, no floor, no oracle key)
WEIGHTED_REWARD = FALSE
```

## Retention contract (frozen)

```text
goal                      rank 0
guidedAdmitted            rank 10
combatProgressAdmitted    rank 20    (first real rank-20 semantics)
ordinary neutral          rank 30
```

```ini
RETENTION_ONLY = TRUE
SCHEDULER = UNCHANGED
  combatProgressAdmitted candidates do NOT enter the guided heap, receive no
  frontier score, and remain schedulable only through the normal neutral/FIFO
  lane; they merely survive cap pressure better than ordinary neutrals.
```

This targets exactly the 5.25t loss shape (cp#8 generated, not in the frontier, not the FIFO head, dropped by cap) without inventing a third scheduling lane.

- Single runs; no tuning; per the predeclared gate, `IF MT4 MISS -> reuse survival audit, report, stop`.
