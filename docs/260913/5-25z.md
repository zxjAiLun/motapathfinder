## Mechanism gap this exposes

The resource skyline is consulted **only for frontier-guided children**:

```text
if (identityInFrontier) {            // rank 10 path only
  if (resourceSkylinePriority) {
    skylineSet.query(...)            // <- Pareto screening lives here
    skylineSet.insert(...)
  }
}
child.combatProgress = ...           // rank 20 path: NO skyline query at all
```

So the weight-free Pareto machinery already exists and already runs - but rank-20 (combatProgress) neutrals bypass it entirely, which is exactly why 29 same-structural-key nodes can coexist in rank 20 with the dominating one dropped.

## Secondary observation: degenerate `equip` identities

All 120 rank-20 `equip` candidates collapse into three buckets - `equip:MT2:undefined,undefined` (113), `equip:MT1:undefined,undefined` (4), `equip:MT3:undefined,undefined` (3) - because `actionToSemanticIdentity` falls through to `${kind}:${floorId}:${x},${y}` and equip actions carry no `x`/`y`.

```ini
EQUIP_SEMANTIC_IDENTITY = DEGENERATE_COORDS_UNDEFINED
```

This does **not** affect the search: the field is observational, and equip identities never match a frontier entry, so `frontierGuided` is unaffected. It would matter only if a future round attempted semantic-diversity retention, which would then see 113 unrelated equipment actions as one identity. Recorded, not repaired.

## Non-claims and limitations

- **Do not** write `RANK20_IS_GLOBALLY_SATURATED_ALWAYS = TRUE`. What is established is saturation at the specific trim where cp#9 dies, in one trajectory.
- "cp#9 dominates 28 peers" is a statement about the **resource vector within an equal-structural-key group**. It is the strongest available weight-free statement, but the structural key is an analytical abstraction, NOT a proven future-legality equivalence - so the 28 peers are not hereby proven redundant.
- Nothing here shows that older rank-20 candidates are generally less valuable, nor that "younger is better".
- `found = false`; this is an observation run, not a qualification run. No capability claim.
- `fifoHeadProtected = 0`: FIFO head protection was never exercised, so this run says nothing about it.
- The peer analysis covers pending candidates at that one trim, not the whole search.
