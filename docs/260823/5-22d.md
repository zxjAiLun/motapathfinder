## 2. 严苛设计原则（Fail-Open & Shadow-Only）

1. **二元分类（Binary Output）**：
   - 仅允许返回 `"definitelyReject"` 或 `"unknown"`。
   - **严禁返回 `"definitelyAccept"`**（0 战损接受必须永远由权威 `evaluateBattle` 模拟判定）。
2. **绝对安全保守原则（Fail-Open）**：
   - 任何涉及特殊技能（阻断特技、吸血、中毒、衰弱、领域、阻击、先攻、反击、多段、支援、光环等）、事件怪物、动态 buff、特殊装备/战斗道具效果（`I821`, `I768`, `I792`, `I793`, `I1491-1493`, `I729`, `I603`, `I597`, `I837-841`, `cross`, `pickaxe`, `centerFly` 等）、战斗标志（`s113`, `s141`, `s142`, `skill`, `magicAtk` 等）的敌人或状态，**一律返回 `"unknown"`**，交由权威解析器。
   - 仅在严格无特殊修饰的标准敌人和标准状态下执行两条可证明的保守数学拒绝：
     - **Rule 1 (无法破防)**：`hero.atk <= enemy.def`。勇士单回合伤害为 0，战斗不可胜或无限回合，必定无法 0 战损。
     - **Rule 2 (无法 1 击必杀且怪物破防破盾)**：`heroDamagePerTurn = hero.atk - enemy.def > 0` 且 `turnsNeeded = ceil(enemy.hp / heroDamagePerTurn) > 1`，怪物至少攻击 `(turnsNeeded - 1)` 次，单次怪物原始伤害 `max(0, enemy.atk - hero.def)`，累计原始伤害 `(turnsNeeded - 1) * max(0, enemy.atk - hero.def) > hero.mdef`。勇士净战损必大于 0。
3. **Shadow Probe 运行模式**：
   - 探针运行并记录其判定，但 **生产代码仍然无条件调用权威 `evaluateBattle`**。
   - 生产搜索决策 100% 保持权威结果，保证 zero production behavior change。

## 3. 合成对抗矩阵验证（`check-auto-battle-fast-reject-matrix.js`）

在 17 组极端边界对抗用例下进行交叉校验：
1. **Vanilla Negative**：
   - `hero.atk < enemy.def` (零破防) -> `definitelyReject` (权威: `damageInfo == null`)
   - `hero.atk == enemy.def` (相等零破防) -> `definitelyReject` (权威: `damageInfo == null`)
   - `turns = 3, enemy.atk - hero.def = 10 > 0 mdef` -> `definitelyReject` (权威: `damage = 20`)
   - `enemyRawDamage = 20 > mdef 10` (破盾) -> `definitelyReject` (权威: `damage = 10`)
2. **Vanilla Positive / Safe (严禁误杀)**：
   - `1-shot kill` (1回合击杀怪物，怪物未出手) -> `unknown` (权威: `damage = 0`, 0战损接受)
   - `total defense` (`enemy.atk <= hero.def`, 多回合怪物不破防) -> `unknown` (权威: `damage = 0`, 0战损接受)
   - `mdef fully absorbs` (原始伤害 10 <= 护盾 20) -> `unknown` (权威: `damage = 0`, 0战损接受)
3. **Enemy Specials (全量 Fail-Open)**：
   - 先攻 (`special: [1]`)、吸血 (`special: 11`)、连击 (`twoHit: true`)、击退 (`repulse: true`)、支援 (`guards: [...]`) -> 全部安全放行 `unknown`
4. **Hero Modifiers / Combat Items / Flags (全量 Fail-Open)**：
   - 升华道具 `I821`、技能标志 `skill: 1`、攻防反转 `s113`、动态增益 `__atk_buff__: 1.5`、异常状态 `poison: true` -> 全部安全放行 `unknown`
5. **矩阵门禁结果**：**17/17 全部通过，`falseRejects === 0`**。
