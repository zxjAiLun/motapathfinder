## 背景与授权目标

PR-5.21b / PR-5.21b1 彻底移除了 stateful exact caches，修复了 A/B accounting 污染与严格指纹回放，完成了 59/59 static suite 的规模重核准，并确立了第一区域在 50000 展开 / 30s 预算下的表现（约 4832 次展开，wallMs 30001ms，peak RSS 215.7MB，内存触顶彻底解除，核心瓶颈为 wall time）。

PR-5.22a 的核心目标为**纯测量与归因（Measurement / Attribution）**：
在不改变任何搜索策略、DP 优先级、剪枝、状态键、缓存语义、预算、worker 或磁盘 frontier 的前提下，测量并量化每次 expansion 的 CPU 与 Wall 成本分布，明确回答各个子系统在每次展开中的耗时占比与调用频次，为 PR-5.22b 的单一热点优化提供精确度量依据。

## 严格限制与约束

1. **PROFILER_OFF 零开销与完全等价**：默认不开启 profiler；开启时不改变任何搜索动作顺序、候选优胜者、生成状态集合、注册状态集合或 frontier。
2. **互斥顶层 Self-Time 与嵌套 Inclusive 分离**：
   - 顶层划分互斥 self-time buckets（如 `walkReachability`、`primitiveEnumeration`、`actionEvaluation`、`applyAction`、`stabilization/autoEvents`、`stateKeyAndDominance`、`frontierQueue`、`otherExpansionOverhead`），确保 self-time 总和不超过 100% 展开耗时。
   - 嵌套 inclusive 指标（如 skeleton cache hit/miss、battle estimates、dominance calls）独立报告，不与 self-time 混淆。
3. **结构计数与环境耗时分离**：确定的整数计数（expansions, registered, cache hits/misses, key builds）与环境耗时（wallMs, cpuMs, averages）严格分离。
4. **有界的慢展开采样（Bounded Slow-Expansion Sampling）**：仅保留 top-N（例如 top 20）慢展开关键统计，严禁记录完整 state/route 导致 profiler 成为内存热点。
5. **绝对禁止提前优化**：本 PR 不允许引入任何算法或缓存优化，仅做度量归因。
