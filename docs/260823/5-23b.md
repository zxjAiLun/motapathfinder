## 1. 目标与背景

PR-5.23a 生产终验重测确认：在纯 Flat Canonical DP 下，从真实 MT1 起点直接向 MT6 展开时，限制瓶颈在于大图平铺搜索下的状态空间保留与 RSS 内存膨胀。

本轮 **PR-5.23b** 聚焦于建立分段搜索机制基础：
1. **轻量 Retention Shape 度量**：在 `shared-solver/lib/dp-search.js` 中建立驻留度量（`nodesSize`, `bestByKeySize`, `agendaEntries`, `acceptedNodesCumulativeByFloor` 等），Fail-closed 默认关闭。
2. **Canonical DP Checkpoint Pool 真实接通与 Fail-Closed 门控**：在 `searchDP()` 中接入 `captureFloorCheckpoints` 门控（生产/基线默认 `false`，仅在 Candidate B 中显式 `true` 启用）。发生真实前向跨层转移时物化完整路径，维护带有确定性父代表命名空间的 Pareto checkpoint 代表。
3. **分段进程级生命周期隔离与真实 Stage 2 执行**：Stage 1 在独立子进程中执行并生成 Pareto 代表序列化产物；子进程退出后操作系统彻底释放 Stage 1 全部堆内存；父进程接收代表并在干净内存环境下启动 Stage 2（MT2 $\to$ MT3）真实搜索。
4. **全量代表 Strict Replay 强断言**：对进入 Stage 2 的全部 8 个 Pareto 代表在独立的全新仿真器实例中执行真实 MT1 起点严格重放，确保 exactStateKey、Chaos 难度与零选择未决 100% 严格一致。

## 2. 核心架构改动与实现

### A. Fail-Closed 门控与 Retention Shape（`shared-solver/lib/dp-search.js`）
- `captureFloorCheckpoints` 默认 `false`，确保 Baseline A 及生产直接搜索零开销、零污染。
- 只有在 `captureFloorCheckpoints: true` 时才执行前向跨层物化与 checkpoint 记录。
- 统计 `acceptedNodesCumulativeByFloor`，修正了 root 重复计数问题。

### B. 确定性 Lineage 命名空间与代表去重（`shared-solver/lib/floor-checkpoints.js`）
- 每个 checkpoint 携带结构化标识：
  - `id`: `${edge}#${localIndex}`
  - `lineageId`: `sourceRepresentativeId ? `${sourceRepresentativeId}|${id}` : id`
  - `sourceRepresentativeId`: 父代表 ID。
- `selectParetoRepresentatives` 使用 `lineageId` 进行去重，确保不同父代表派生出的同名本地索引 `#0` 不会发生静默冲突，完整保留不同 MT1 投资路线进入 MT2 后产生的不同未来。

### C. 进程级阶段内存隔离与真实 Stage 2 推进（`check-onlyup-structured-planning-ab.js`）
- **Baseline A**：在独立子进程中运行未受污染的 Flat Canonical DP，断言 `captureFloorCheckpoints: false` 与 `RESOURCE_LIMIT` 退出。
- **Candidate B Stage 1 (MT1 $\to$ MT2)**：子进程完成 MT1 $\to$ MT2 搜索，采集 50~96 个 checkpoint，提取 8 个多元 Pareto 代表并退出释放内存。
- **Candidate B Strict Replay**：对 8 个代表分别启动干净仿真器执行真实路线决策重放，断言 100% 通过（0 mismatches, StateKey 严格一致）。
- **Candidate B Stage 2 (MT2 $\to$ MT3)**：在全新干净内存环境下使用 8 个代表作为输入前沿启动 Stage 2 搜索（实际执行 1,400~3,000 expansions，Stage 2 峰值 RSS 仅 ~218~256MB）。

## 4. 结论与事实界定

### 已严格证明 (PROVEN)
1. **真实前向 Checkpoint 捕获**：Canonical DP 能够在真实前向转移上正确捕获 checkpoint，并带有物化路径。
2. **Pareto 代表多样性真实存在**：Stage 1 成功提取了 HP 5524 的极限省血代表与 HP 1475 / ATK 72 / DEF 35 / LV 4 的战斗投资代表，证明了分段代表不会退化为单一最高 HP 贪心。
3. **保留代表 100% Strict Replay 验证**：全部 8 个代表均经由干净仿真器从真实 MT1 起点成功重放，`exactStateKey` 与 `Chaos` 难度 100% 严格一致。
4. **分段生命周期内存隔离与 Stage 2 实际启动**：Stage 1 内存被操作系统完全回收，Stage 2 成功在独立干净内存环境中启动并执行了 1,400+ expansions。

### 尚未证明 / 当前能力边界 (NOT YET PROVEN)
1. **跨入 MT3 / MT6 的能力突破**：在当前 MT2 怪物数值强度下，单从 MT2 入口就地搜索尚未能直接突破至 MT3，最深停留仍为 `MT2`。
2. **生产环境直接晋升**：因此 `promotion: false`，机制合格但能力尚待跨层规划器突破。
