## 0. 动机（为什么不再堆 changeFloor feature）

已有证据组合：

```text
kind-prior overall        0.3399   ← 比 learned model 强
V2 learned overall        0.3581
V2 battle within-kind     0.3965   ← 确实学到局部选择
V2 changeFloor            0.8125   ← 仍然反向
```

monolithic pairwise 把两件事混在一起学：

```text
A. 跨 kind calibration（该选哪一类动作）
B. within-kind discrimination（定了类之后选哪一个）
```

既然 trivial kind-prior 在 A 上已经更强，就不要让 MLP 把 A 学坏：**A 交给固定 kind prior，
MLP 只学 B。**

## 1. 冻结协议

```ini
KEEP = FEATURE_SCHEMA_V2 / CORPUS / MAX_REACHED_SPLIT / 16_HIDDEN / SEED 52501 / EPOCHS 300 / LR 0.05 / T 1.0
CHANGE = MONOLITHIC_PAIRWISE -> SAME_KIND_RESIDUAL_PAIRWISE + FIXED_KIND_PRIOR

DO_NOT = ADD_FEATURES / EXPAND_CORPUS / TUNE_PRIOR_WEIGHT / TUNE_TEMPERATURE
         CHANGE_MODEL_SIZE / FIX_CHANGEFLOOR_BY_RULE / CONNECT_MCGS
```

组合方式（无任何可调权重 / 无 calibration sweep）：

```text
residualCentered(a) = r(a) - logsumexp(r(b), b in same kind) + log(N_k)
finalScore(a)       = log(P_train(kind = k)) + residualCentered(a)
```

退化性质（已断言）：若 residual 在同 kind 内完全打平，则 `residualCentered = 0`，
`finalScore = log(kindPrior)` **精确成立**——treatment 在“没学到东西”时退回已经很强的
kind-prior baseline，而不是某个任意东西。driver 对 41 维合法向量 fail-closed 断言该性质。

## 5. 解释与 caveat

```ini
PR_5_25H = HIERARCHICAL_RESIDUAL_PASSED_OFFLINE
OFFLINE_FACTORIZATION = WORKS (overall 0.3399->0.2891; changeFloor 0.8125->0.1250)
ROLLOUT_CAPABILITY_GAIN = NONE_OBSERVED (0 terminal, 0 MT4, 0 MT5; MT3 1/32 vs 0/32)
```

- **offline 层面，factorization 假设成立**：固定 kind prior 做跨 kind、MLP 只做 within-kind
  residual，同时改善了 overall micro（首次低于 kind-prior）并显著修好了 changeFloor。
  这说明 5.25g 的“楼梯反向”里有相当部分其实是**跨 kind 校准把 within-kind 排序带坏了**。
- **但 offline 改善没有转化为 rollout 能力**：两臂都卡在 MT1/MT2（treatment 仅 1/32 到 MT3），
  0 MT4 / 0 MT5 / 0 blueKing terminal。这不是“treatment 比 control 差”，而是**两者都远未接近目标**。
- **重要对照发现**：CONTROL 是纯 kind-prior 策略（几乎只会挑最常见的动作类别），它自己就能到
  MT2（24/32），treatment 也只多到 MT3 一次。也就是说，**这段 rolling 的瓶颈当前不是
  “within-kind 选哪一个”，而是 proposal distribution / horizon 本身**：T=1.0 softmax 在 96 步内
  没有把 rollout 推到跨层不可逆进展（与 5.25b/5.25c 的 terminal 结论一致）。
- caveat：`unique changeFloor` 只有 **n=16**（且 TRAIN 里 changeFloor 只有 20 pairs / 9 signatures），
  0.8125→0.1250 的移动幅度很大但样本很薄；battle 略有变差（0.3965→0.4156，仍 < 0.5）。
  未做显著性检验。
- 未做的事：不加 feature、不扩 corpus、不调 prior 权重 / 温度、不改模型大小、不用手工规则修
  changeFloor、不接 MCGS。
