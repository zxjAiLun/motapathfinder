## 0. 动机

`normalizeAction()` 与 `fingerprintAction()` 都把 changeFloor 的**目的楼层**作为动作身份的一部分
（`changeFloor.floorId/toFloor/floor`、destination x/y），但 `FEATURE_SCHEMA_V1` 的 action features
只有 kind / path length / direction / 当前层 target dx,dy / estimate——

> 模型知道“我要走一个楼梯”，却不知道“这个楼梯把我送去哪个楼层”。

这与 5.25e 的 `unique changeFloor = 0.9375`（近乎反向）高度吻合。本 milestone 做第一次真正的
**representation 修改**，只补一个 feature。

## 2. 关键实现事实（否则会静默出错）

**语料里所有枚举出的 changeFloor 目的楼层都是相对值，没有一个是绝对值**：

```text
28 条 changeFloor 枚举动作：absolute MTx = 0 | ':next' = 8 | ':before' = 20
normalized.targetFloorId 出现次数 = 0
```

因此若按字面 `floorOrdinal(":next")` 会得到 **0**，delta 会被静默算错。
正确做法是先按 `project.floorOrder` 解析（canonical 语义见 `lib/floor-transitions.js`
的 `resolveRelativeFloor`），再取 ordinal。

**fail closed**：若 changeFloor 的目的楼层缺失 / `:next`/`:before` 无法解析 / 解析结果不是 `MT<n>`，
则**整条 route 以 `changefloor-destination-unresolved@N` 排除**（记录原因），不静默编码 0。
本轮实测：28 条 replayable route 全部解析成功，**无一条被排除**。

## 3. 初始化 hardening（只新增一个输入）

输入维度 40→41 后，若沿用原 `1/sqrt(inputDim)` 与单一 RNG 流，输出层权重也会轻微改变。
为让 A/B 更接近“只新增一个输入”：

```text
V2 前 40 列输入权重 + 输出层 w2：使用与 V1 完全相同的 base stream（同 seed、同 scale 1/sqrt(40)）
V2 第 41 列：单独 deterministic stream（extensionSeed = seed ^ 0x9e3779b9，scale 1/sqrt(41)）
```

已断言：`V1 first-40 columns identical in V2 = true`、`w2 identical = true`、`b1/b2 identical = true`、
`plain V1 reproducible = true`，且 V2 前缀在所有捕获动作上与 V1 逐值相等。

## 6. 解释与 caveat

```ini
PR_5_25G = REPRESENTATION_REPAIR_FAILED_OFFLINE
DESTINATION_FEATURE_EFFECT = DIRECTIONAL_IMPROVEMENT_ON_EVERY_METRIC
CHANGEFLOOR_FIXED = FALSE (0.8125，仍近乎反向)
OVERALL_BEATS_KIND_PRIOR = FALSE (0.3581 > 0.3399)
ROLLOUT = NOT_RUN (gates not passed)
```

- 仅补上“目的楼层”（升/降、跨几层）**确实让每个指标都方向性变好**：
  changeFloor 0.9375→0.8125（occurrence 0.8913→0.6957）、overall 0.3821→0.3581、
  unique aggregate 0.4837→0.4529、battle 0.4125→0.3965。
- 但**没有把 changeFloor 从“反向”修成“正向”**，也没有让整体超过 kind-prior。
  因此“模型不知道目的楼层”**不是**唯一瓶颈；即使知道升/降，模型仍系统性挑错换层动作。
- **统计 caveat**：gate 用的 unique changeFloor 只有 **n=16**，方差极大；0.9375→0.8125 的移动
  不能排除噪声。occurrence（n=46）改善更大（→0.6957），同样仍未过 < 0.5。
- 未做的事（按协议）：不改 hidden/LR/epochs、不加第二个 feature、不动 battle representation、
  不扩 corpus、不跑 rollout、不接 MCGS。
