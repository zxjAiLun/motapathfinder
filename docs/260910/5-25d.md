## 2. Step 0：non-overlapping corpus inventory（本轮已完成）

### 2.1 方法

只做只读 inventory，不训练：

1. 扫描 `shared-solver/routes/fixtures` + `routes/latest` 全部 `*.route.json`。
2. 对每条 route 从 chaos MT1 初始状态做严格 replay；decision identity =
   `(buildStateKey(reconstructed state), chosenActionFingerprint)`。
3. 按 final floor 分成 TRAIN family（`final <= MT3`，排除 MT4/MT5 qualification family）
   与 HELD-OUT family（`final >= MT4`）。
4. 统计 held-out decisions 中 signature 不出现在 TRAIN union 的数量。

历史 key 三态（route 由多代 solver 写出，逐 route 自动探测）：

```text

dominance  hero.hp/hpmax/manamax = null（当前 buildDominanceKey 形状）
canonical  不置空（当前 buildStateKey 形状）
# 三者都额外为 snapshot.floors 中每个 floor 补空 mutation（历史 serializer 行为）
```

复现命令与产物：


## 4. 注册 split 规则（review precondition，已修正）

评审指出原实现 `finalFloor <= MT3` 的推论不严格成立：solver 支持跨层返回 / `floorFly`，
一条 route 可以 `MT1→MT2→MT3→MT4→回到 MT3` 而 `finalFloor = MT3`，训练数据却已含 MT4 行为。
因此资格判定**必须按 replay 过程中实际达到过的最大 floor**，而非最终 floor：

```ini
TRAIN_ELIGIBLE    = start == CHAOS_MT1 AND maxReachedFloorOrdinal <= 3
HELD_OUT_ELIGIBLE = start == CHAOS_MT1 AND maxReachedFloorOrdinal >= 4
                    # near layer: maxReached == 4 (MT4)
                    # deep layer: maxReached >= 5 (MT5/MT7)
MT4_FIXTURES      = HELD_OUT
```

实现：`replayRouteFile` 记录 `maxReachedFloorOrdinal`（start state 与每次 apply 后的 state 取最大）；
driver 对 split 结果做 fail-closed 断言（任何 TRAIN route `maxReached >= 4` 即报错）。

```text
修正前 final-floor split : TRAIN 15 / HELD-OUT 9
修正后 maxReached split  : TRAIN 15 / HELD-OUT 9   <- 本 corpus 上数值不变
TRAIN maxReached 分布    : {MT2/max2: 4, MT3/max3: 9, MT2/max3: 2}
```

即：本 corpus 中**没有**任何原本进入 TRAIN 的 route 实际到达过 MT4+，所以原划分结果恰好相同，
但原推理并不成立；修正后该规则**由构造保证**成立。

### 5.1 P1 发现：该 gate 通过被 trivial baseline 完全解释

加入只依赖 TRAIN action-kind 频率（Laplace 平滑、**不含任何 state 特征**）的 baseline 对照：

```text
kind-prior baseline micro rank : 0.3399   <--- 优于 learned model
learned model micro rank       : 0.3821
uniform                        : 0.5000
```

冻结的 gate（`< 0.5`）虽然 PASSED，但**一个只偏好高频动作种类的 baseline 同样通过、而且比
learned model 更好**。因此：

```ini
FROZEN_GATE_PASSED = TRUE
GATE_PASS_IS_BASE_RATE_ARTIFACT = TRUE   # model 0.3821 > baseline 0.3399
LEARNED_GENERALIZATION_SIGNAL = NOT_ESTABLISHED
```

结论：`NON_OVERLAP_CHOSEN_ACTION_RANK < 0.5` **不足以作为“学到了可泛化信号”的判据**，
它会被 base rate 轻易通过。要判断 learned prior 是否有真实增益，gate 必须是
**baseline-relative**（例如 `model_rank < kind_prior_baseline_rank`），而不是 `< uniform`。

### 5.2 因此不进入 rollout

评审规则是“gate 过了才值得烧 real rollout”。此处 gate 虽字面 PASSED，但已被证明是
base-rate artifact，**不构成 learned capability 证据**，所以本轮**不运行 CONTROL/TREATMENT rollout**
（`PHASE_2_MCGS` 继续未授权）。rollout 是否值得运行，应在评审冻结 baseline-relative gate 之后决定。
