## 0. 动机

5.25e Repair 1 之后：`UNIQUE_BATTLE = 0.4125`（n=102，低于 uniform 0.0875），aggregate 0.4837。
但 battle 子集可能只是 `estimate.damage` / `estimate.turn` 的简单启发式。本 milestone 用
**一个固定、未拟合**的 estimate-only baseline 直接对照。

## 1. 冻结协议（不做 baseline fishing）

```ini
MAIN_MODEL = UNCHANGED_5_25D_MODEL
EVALUATION = UNIQUE_SIGNATURE + BATTLE_ONLY + SAME_KIND_ONLY
ESTIMATE_BASELINE = LEXICOGRAPHIC_LOWER_IS_BETTER
PRIMARY_KEY_1 = estimate.damage (lower is better)
TIE_BREAK_KEY_2 = estimate.turn (lower is better)
BOTH_EQUAL = tie

NO_FITTING = TRUE
NO_WEIGHT_TUNING = TRUE
NO_SWEEP = TRUE          # 不做 damage-only / turn-only / 多权重 sweep
NO_NEW_TRAINING_RECIPE = TRUE
NO_MODEL_CHANGE = TRUE
NO_EXTRA_FIT_OBJECTIVE = TRUE
DETERMINISTIC_MODEL_REPRODUCTION = TRUE

EXPAND_CORPUS = FALSE
FIX_CHANGE_FLOOR = FALSE
RUN_ROLLOUT = FALSE
CONNECT_MCGS = FALSE
```

**公平性约束（关键）**：若某 decision 的**任一同-kind battle alternative** 缺失有效
`estimate.damage` 或 `estimate.turn`，该 decision 对 baseline 不可评估；最终比较在**完全相同的
intersection subset** 上同时重算 full model 与 estimate baseline，绝不用 full model 的更大集合去比。

## 3. Tie 诊断（避免把 tie-degenerate 误读成“baseline 无效”）

```text
decisionsWithChosenEstimateTied             : 67 / 102
decisionsAllAlternativesTiedWithChosen      : 25 / 102     # 该子集 estimate baseline 恒为 0.5
decisionsWithUniqueChosenEstimate           : 35 / 102
totalTiesWithChosen                         : 127
sameKindSizeHistogram                       : {2:31, 3:17, 4:16, 5:4, 6:6, 7:9, 8:10, 9:5, 10:4}
```

**fully-tied 子集（最强证据）**：25 条 decision 上，所有同-kind alternative 与 chosen 的
`(damage, turn)` 完全相同，因此 estimate baseline **由构造成恒为 0.5**：

```text
FULL_MODEL on fully-tied subset : 0.4320  (n=25)
ESTIMATE on fully-tied subset   : 0.5000  (by construction)
```

模型在 estimate 完全无法区分的地方仍做到 0.4320，说明它确实使用了 `estimate.damage/turn`
之外的信号（tie-breaking beyond estimate）。

## 4. 锁定解释规则

```text
FULL_MODEL >= ESTIMATE_ONLY
  -> 没有证据表明 battle signal 超出了“优先即时损伤更低/回合更少的战斗”这一简单启发式。

FULL_MODEL < ESTIMATE_ONLY
  -> battle ranking 中存在 estimate.damage/turn 之外的额外信号；
     但仍不能叫 strategic planning，只能记：
     EVIDENCE_BEYOND_DAMAGE_TURN_ESTIMATE = OBSERVED
```

本次结果落在后者：

```ini
EVIDENCE_BEYOND_DAMAGE_TURN_ESTIMATE = OBSERVED
PRIMARY_COMPARISON = TRUE   (0.4125 < 0.4971)
FULLY_TIED_SUBSET = 0.4320 < 0.5000 (estimate 恒为 0.5)
```

## 5. Caveat（不得省略）

1. **不等于 strategic planning**：其他 feature 里仍有位置、enemy/item indicator、hero stat
   等局部信息；`EVIDENCE_BEYOND_DAMAGE_TURN_ESTIMATE` 只排除**单一 (damage, turn) 字典序启发式**。
2. **estimate baseline 本身偏弱且 tie 很重**：67/102 有 tie、25/102 全 tie，故 aggregate
   0.4971 ≈ uniform 有一部分是 tie 结构造成，而不是纯粹的“该启发式有强预测力但被击败”。
   因此 fully-tied 子集的 0.4320 是比 aggregate 更干净的证据。
3. **非 i.i.d.**：102 个 unique signature 来自 9 条 held-out route / 少数 lineage，不能当独立样本。
4. **无显著性检验**：本 milestone 按冻结协议只给固定点估计对照，不做统计检验。
5. **整体 policy 仍不合格**：总体 rank 输给 kind-prior，且 `changeFloor = 0.9375` 近乎反向信号。


即使 full model 赢了 estimate baseline，**也不进入 rollout**：整体 policy 仍有两个已知问题
（总体输给 kind-prior；`changeFloor ≈ 反向信号`），拿它去 rollout 很容易被换层行为直接毁掉。
下一步需要评审决定（例如先诊断 `changeFloor`，或改 objective/feature），本 milestone 不自行扩展。
