## 0. 动机

5.25d 把问题从 “corpus quantity” 缩小到 `REPRESENTATION / LEARNING OBJECTIVE`。
但 5.25d 的总体 rank 里，action-kind 的全局 base rate 影响很大（kind-prior baseline 0.3399
甚至优于 model 0.3821）。所以需要消掉这一层，看模型在**同 kind 内部**是否还能区分。

## 1. 冻结约束

```ini
RETRAIN = FALSE
MODEL_CHANGE = FALSE
DATA_CHANGE = FALSE
OBJECTIVE_CHANGE = FALSE
ROLLOUT = FALSE
MCGS = FALSE
CORPUS_EXPANSION = FALSE
```

模型由与 5.25d **相同的 deterministic preparation path** 复现（feature schema v1 / 16-hidden MLP /
`softplus(-(chosen-neg))` / seed 52501 / epochs 300 / lr 0.05）；本诊断**不定义新模型、不改数据**。

## 2. 指标定义

对每条 unseen held-out decision：

```text
chosenKind      = kind(chosen action)
sameKindLegal   = { 该 decision 的全部 legal actions 中 kind == chosenKind 的动作 }
if |sameKindLegal| < 2: 该 decision 不可评估（排除）
else: 只在 sameKindLegal 内给 chosen 排名（ties 记半分），
      WITHIN_KIND_NORMALIZED_RANK = (rank - 1) / (|sameKindLegal| - 1)
```

- `WITHIN_KIND_UNIFORM_BASELINE = 0.5`（按定义）。
- 内置 sanity：`TRAIN_ACTION_KIND_PRIOR` 在同 kind 内是常数，因此其 within-kind rank 必须**恰好 0.5**；
  driver fail-closed 断言该检查。

## 4. 解释（licensed interpretation）

消掉全局 kind base rate 之后：

```ini
WITHIN_KIND_AGGREGATE = 0.4385   # 略优于 uniform(0.5)，但幅度小
WITHIN_KIND_MODEL_RANK = 0.4385
WITHIN_KIND_UNIFORM_BASELINE = 0.5
PER_KIND_SIGNAL = HETEROGENEOUS
```

- **`battle` 内部存在真实（且不小）的 state-conditional signal**：284/330 的可评估 decision、
  rank 0.3651；模型能在同层同类的多个战斗里挑得比随机好。
- **`changeFloor` 内部显著劣于 uniform（0.8913，top1 0.109）**：模型在同 kind 的换层选项里
  系统性地挑错（接近“几乎总是选错”）。
- 因此 5.25d 的总体 `0.3821` 与 kind-prior `0.3399` 的对比，属于**口径问题**：
  总体 rank 被 kind base rate 主导；消掉后模型的净值只有 **0.4385**，且是
  “battle 有用信号 + changeFloor 有害信号”的混合。

允许声明：

> 冻结的 `FEATURE_SCHEMA_V1 + 16-hidden pairwise` 模型并非“什么都没学到”：
> 它在 `battle` 决策上展现出可测的 within-kind state-conditional ranking signal；
> 但在 `changeFloor` 上表现为有害，aggregate within-kind rank 仅 0.4385（略优于 uniform）。
> 总体 `< uniform` 的通过度不能作为泛化证据（已被 kind-prior 反超）。

不得扩大为：`learned prior 有效/无效`、`特征设计不可行` 等一般性结论。

### 4.1 未解决的 interpretation caveat（下一轮候选，未授权）

`battle` 的 within-kind signal 可能退化为**简单启发式**（例如“优先 estimate.damage/turn 更小的战斗”），
因为 feature 里 `estimate.damage/turn` 本身就是强信号。当前诊断**不能**排除这一点。
若要区分“state-conditioned 策略”与“单特征启发式”，需要一个只用 `estimate.*` 子特征的
within-kind baseline 对照（属于新诊断，需新授权）。
