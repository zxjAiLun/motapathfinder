## 0. 动机

5.25d 把问题从 “corpus quantity” 缩小到 `REPRESENTATION / LEARNING OBJECTIVE`。
但 5.25d 的总体 rank 里 action-kind 的全局 base rate 影响很大（kind-prior 0.3399 甚至优于
model 0.3821），所以需要消掉这一层，看模型在**同 kind 内部**是否还能区分。

## 2. 指标定义

对每条 unseen held-out decision：

```text
chosenKind      = kind(chosen action)
sameKindLegal   = { 该 decision 的全部 legal actions 中 kind == chosenKind 的动作 }
if |sameKindLegal| < 2: 不可评估（排除）
else: 只在 sameKindLegal 内给 chosen 排名（ties 记半分），
      WITHIN_KIND_NORMALIZED_RANK = (rank - 1) / (|sameKindLegal| - 1)
```

Repair 1 同时报告两种权重：

```text
occurrence-weighted : 每条 held-out route occurrence 计一次
unique-signature    : 每个 (buildStateKey(state), chosenFingerprint) 计一次
```

signature 已固定 state，因此同一 signature 的 legal set、可评估性与 within-kind rank 完全相同，
去重只改变**权重**。内置 sanity：`TRAIN_ACTION_KIND_PRIOR` 在同 kind 内恒定，其 within-kind
rank 必须**恰好 0.5**（两种权重都断言）。

## 3. 结果

```bash
npm run check:learned-prior-within-kind-diagnostic --prefix shared-solver
# -> shared-solver/routes/generated/learned-prior-within-kind-diagnostic.result.json
```

```text
reference overall        : model 0.3821 | kind-prior 0.3399 | uniform 0.5000
held-out unseen          : 423 occurrences -> 154 distinct signatures (amplification 2.75x)
kind-prior within-kind   : occurrence 0.5000 | unique 0.5000  (sanity PASS, exactly 0.5)
```

| weighting | evaluable | aggregate rank | battle | changeFloor |
| --- | --- | --- | --- | --- |
| occurrence-weighted | 330 / 423 | **0.4385** | n=284, **0.3651** (top1 0.451) | n=46, **0.8913** (top1 0.109) |
| unique-signature | 118 / 154 | **0.4837** | n=102, **0.4125** (top1 0.382) | n=16, **0.9375** (top1 0.063) |

排除分布（unique）：`{battle: 26, changeFloor: 8, equip: 1, pickup: 1}`。

**关键观察**：去掉重复 signature 后 aggregate 从 `0.4385 → 0.4837`（几乎回到 uniform），
说明 occurrence-weighted 的 aggregate 有相当一部分来自 **trajectory duplication 放大**；
但 `battle` 子集仍保持 `0.4125`（低于 uniform 0.0875），并未回到 0.5。

## 4. 解释（licensed interpretation）

```ini
OCCURRENCE_WEIGHTED_WITHIN_KIND_SIGNAL = OBSERVED_ABOVE_UNIFORM          # aggregate 0.4385
DISTINCT_SIGNATURE_AGGREGATE = WEAK_ABOVE_UNIFORM                        # 0.4837，接近 uniform
DISTINCT_SIGNATURE_BATTLE = 0.4125 (margin 0.0875 below uniform)
DISTINCT_SIGNATURE_CHANGEFLOOR = 0.9375 (above uniform, harmful)
DISTINCT_SIGNATURE_SIGNAL = ESTABLISHED (advisory margin 0.05)
```

允许声明（严格限定）：

> 在 occurrence-weighted held-out decisions 上，`battle` 的 within-kind rank 明显优于 uniform；
> 在去除跨 route 重复 signature 后，`battle` 子集仍保持 `0.4125 < 0.5`（低于 uniform 0.0875），
> 而 aggregate 回落到 `0.4837`（接近 uniform）。

不得写成“`battle` 内部存在真实（且不小）的 state-conditional signal”这类无限定语：
在去除重复 signature 之前，不能把它解释成**独立 state-conditioned generalization evidence**。

### 4.1 保留的 caveat

1. **advisory margin**：`0.05` 只是 reporting threshold，不是 statistically established criterion
   （与 5.25d 的 `50/20` 同理）。
2. **非独立样本**：118 个 evaluable unique signature 仍聚集在 9 条 held-out route / 少数 lineage 内，
   不是 i.i.d. 样本。
3. **可能退化为启发式**：`battle` 信号可能只是 `estimate.damage/turn` 的简单启发式
   （feature 里这两项本就是强信号）。当前诊断**不能**排除。→ 见 §5。
