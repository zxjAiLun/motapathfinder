## 背景与收口目标

PR-5.21b 完成了 exact stateful caches 移除、A/B accounting 继承修复、route-store 双方言与严格指纹模式，以及第一区域直接闸门重测。
Review 指出 2 个合同层问题需执行 PR-5.21b1 收口：
1. `check-action-expansion-cache-correctness.js` 中的 100-expansion consistency 仅比较了两个 independent simulator 的相对一致性，未将 `frontierSize === 53`、`generated === 342`、`registered === 171`、`stoppedReason === null` 及 `bestProgressState` 的 exact key 字符串硬锁为固定回归契约。
2. `scripts/generate-solver-manifest.js` 缺失了历史积累的 `TEST_OVERRIDES` 与完整 `static.requiredChecks`，导致 `manifest:refresh` 会冲掉 curated metadata。
3. `check-action-expansion-cache-correctness.js` 需在 generator 中显式标注为 `grade: "local-regression"`, `cleanCheckout: true` 并进入 `static.requiredChecks`。
4. `check-onlyup-first-region-real-route-gate.js` 将 `bestProgress || bestSeen` 严格收紧为 `assert.ok(result.bestProgress)`，不再允许 `bestSeen` 降级。

本轮不改搜索算法、不改缓存策略、不改预算，亦无需重新跑 30s MT6 长闸门（保留 5.21b 的 4832 / 30.001s / 215.7MB 证据）。

## 任务完成与实现细节

### 1. 补强 100-Expansion Regression Contract
在 `shared-solver/check-action-expansion-cache-correctness.js` 中冻结固定基准：
- `EXPECTED_FRONTIER_SIZE = 53`
- `EXPECTED_REGISTERED = 171`
- `EXPECTED_GENERATED = 342`
- `EXPECTED_STOPPED_REASON = null`
- `EXPECTED_BEST_PROGRESS_KEY` = 包含 MT2 / hero / inventory / flags / mutations 的完整归一化 JSON 字符串。
- 同时保留两全新独立 simulator 的确定性一致性比较。

### 2. 同步 Manifest Generator 并实现零差异幂等
- `shared-solver/scripts/generate-solver-manifest.js` 补齐与 `37e6c84` 对齐的完整 `TEST_OVERRIDES` 与 58 个 `static.requiredChecks`。
- 新增 `shared-solver/check-action-expansion-cache-correctness.js` 至 `TEST_OVERRIDES`（`cleanCheckout: true`, `grade: "local-regression"`）并加入 `static.requiredChecks`（扩展为 59 个 requiredChecks）。
- 验证 `npm run manifest:refresh` 与连续二次 refresh 得到零差异（zero-diff idempotent）。

### 3. First-Region Checker 合同收紧
- `shared-solver/check-onlyup-first-region-real-route-gate.js` 移除 `result.bestProgress || result.bestSeen` fallback，严格执行 `assert.ok(result.bestProgress)`。

### 4. 衍生 Reachability 测试基线同步
- 同步 `check-battle-evaluation-projection.js`、`check-reachability-rebase-attribution.js`、`check-remaining-materialization-attribution.js`、`check-topology-first-materialization.js` 中因 exact cache 移除后（每次 reachability 均通过 safeFast/skeleton 重建，消除 stale exact hit）的 rebase/materialization 计数。
