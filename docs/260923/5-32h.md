## 初始设计（A/B结果前冻结）

单一新option：`continuationSlice.dualOriginBoundedService: true`，默认OFF；OFF保持旧语义与序列化形状。启用时包含既有 exact-state representative handoff，并仅改变slice内部的来源服务，不改变全局agenda。

- 每个进入slice local view的节点有且只有一个provenance：`native` 或 `borrowed`。
- fair-served slice root 是 native；其新注册子代继承父节点来源。
- 既有live/unexpanded/exact representative通过真实dominance-rejected successor借入，标记borrowed；不re-register/reparent/re-rank/reorder global queue，不改DP key/dominance/K。
- local native/borrowed各用同一个原slice comparator排序；源内优先级仍用已有rank，不继承旧FIFO序号。
- deterministic work-conserving RR：下一来源初值borrowed（root刚作为native被服务）；选优先来源若非空，否则选另一非空来源；**每次实际服务后下一目标切到另一来源**。空来源不浪费pop；双方持续非空时native/borrowed交替。节点最多展开一次。
- 两侧仍共享同一总K；slice预算用完/前沿排空后所有live survivors照旧在全局agenda中的原有节点/序号等待。无额外expansion和borrowed专属K。
- multi-root启用显式拒绝；不支持observer控制语义；observer只读。每slice compact diagnostics记录K consumed、N/B服务序列、admissions、accepted descendants、pops/expansions、stale duplicate-expansion guards。
- 搜索语义fingerprint：off/absent保旧字段；on加入明确canonical字段；problem fingerprint不变。durable runAttempt完整透传。

## Iteration 1 — Implementation and focused gates (A/B pending)

The runtime option `continuationSlice.dualOriginBoundedService` is default-OFF; when enabled it implies the existing exact-live representative handoff. Per-slice local frontier is held as two heaps using the existing rank comparator; the `fairQueueOrdinal`/oldest FIFO stream is not imported. The fair-served root is native and first consumes one unit of the existing K; borrowed source is the next desired turn. Every actual service flips the desired origin, falling back to the other nonempty heap when needed. A newly accepted child inherits only its generating local parent's provenance. One shared node-ID set prevents dual admission and original global nodes/rank/parent remain untouched.

Diagnostics expose per-slice `{budget, consumed, serviceSequence, bothOriginsAvailable, native/borrowed admitted/popped/acceptedDescendants/expansions, duplicateExpansionPrevented}` and total counters. Accepted descendants count newly accepted direct successors of an expansion served under that origin, including the final-K expansion; admissions count only nodes actually placed in a local view. `native expansions + borrowed expansions == continuationSliceLocalExpansions`; root expansion is native. No solver evidence yet implies route improvement.

Focused checks passed before the paired run: `node --check` changed JS; `check-continuation-confluence-contract.js` (strict N/B alternation when both nonempty, work-conserving fallback, borrowed descendant role inheritance, K=1 identity, cycles, no duplicate pop, observer-independence and multi-root fail-closed); existing continuation-slice contract; search semantics identity/recovery; real durable `runAttempt` forwarding + strict replay; core; manifest (174 modules / 232 tests); no tower-local solver JS.
