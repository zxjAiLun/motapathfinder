## Iteration 2 — 结论：拓扑/state 边界不成立，dual-origin 有界服务作为下一候选设计

在本轮检验的ancestry/depth/empty-roundtrip候选门中，未找到同时保留已知P16正例并过滤已观察负例的规则；这仅是对这些候选类的结论，不是所有可能state/topology gate的普遍否定。

### 证据

- **拓扑事实**：全部handoff的代表都不是当前root的树后代（`rootAncestorOfRepresentative`=0）；代表parent在root祖先链上的只有294次（local pop 201）。P16正例LCA=748，root深度45、代表47；P7负例LCA=47，root/代表同深38。
- **第一次真实分歧（ordinal 102）**：root5 → 返回TS12的node349 → 旧node24。LCA=0、root depth31、代表depth33、代表parent不在root祖先链——**“排除祖先”和“只接更深”两个候选规则都放行它**。
- **canonical仅差floorId**：不止P7。固定选样的32例root/source对中**13例**canonical key只差`floorId`（`__leaveLoc__`等flags全部保留）。
- **正负例不可用“空往返”分开**：P7返回后canonical只差floorId；而P16正例的root→source差异里，TS13的`added`全是**新增雷区**（`2,6/2,7/1,8`），**没有任何`removed`被撤销**，另有hero位置/exp/hatred变化。“有增无减”的解路往返与P7形式相同，硬禁会误伤。

### 被反例否定的边界

| 候选规则 | 反例 |
|---|---|
| 排除“代表是root祖先” | 两个正例也都不是root后代，该门没有目标 |
| 代表parent必须是root祖先 | 放行ordinal 102；并且在合法canonical parent选择下会翻转结论 |
| 代表必须比root更深 | 放行ordinal 102；同样可因合法parent选择翻转 |
| 禁止空往返借用 | 同一state测试会连带删掉P16正例（正例的差异不只在floorId） |

**结论（范围受限）**：在本轮检验的 ancestry/depth/empty-roundtrip 类门控中，没有找到同时保留已知P16正例并过滤已观察负例的通用规则；这不是对所有可能topology/state predicate的普遍不可能性证明。此前设想的“排除祖先”方向被本轮实证否定。
