## 问题与已有证据

PR-5.24d 终审（Real Run 2）确立了重要科学结论：
1. **多样性数量与调度机制不是瓶颈**：单次真实 anchor 重新扩展即保留了 16 条不同历史，且调度器成功实施了完全独立的下游探测试算（每条 200 步扩展）；
2. **瓶颈在于历史生成的同一性**：这 16 条历史在通用下游目标度量下全部表现为 `NO_MEASURABLE_PROGRESS`（0/16 推进）。原因在于现行 DP 目标与前沿保留机制默认均为“省血型”（血量优先、规避消耗），生成的候选历史全都在同一类保守解空间中打转，未生成愿意付出短期代价（扣血、花钱、耗钥匙、绕路）换取关键长期资源（ATK/DEF/MDEF/EXP/升级/装备/关键门开放）的反常识前史。

PR-5.24e 目标：当正常省血路线全部失效时，自动识别并生成具象的投资型 Counterfactual 子目标，通过规范 DP 搜索物化为全新的可行前史。

## 范围与非目标

本轮范围：
- 新增独立模块：`shared-solver/lib/counterfactual-repair.js`；
- 核心接口：`buildCounterfactualRepairIntents({ simulator, startCandidates, triggerFailure, failedSegment, candidateLimit })`；
- 投资机会定义（Investment Trade-off）：必须存在持久收益（ATK/DEF/MDEF/HP上限机会/EXP/等级/装备/物品/不可逆阻挡消除），并允许代价（扣当前HP/花钱/消耗钥匙）；
- Pareto 支配与类型覆盖：对收益维度（更大越好）与代价维度（更小越好）实施严格无权重 Pareto 支配筛选，并在非受控维度上按类别覆盖（stat, exp/level, equipment, item/resource, path/unlock）；
- 严禁直接伪造历史：scanner/evaluator 的 `record.after` 仅作为 candidate-generation evidence，必须将 intent 转化为具象的子目标（Concrete Subgoal），由规范 DP / 仿真器再次真实执行产生规范状态与路线；
- 触发条件严格受控：仅当当前深度至少 1 条真实历史完成 probe、且 `positiveProgressHistories === 0`、全局 stop 为 null 且属于信任的失败类时触发；
- 单轮限制（One Round Only）：第一版仅允许 1 轮 counterfactual generation，不进行递归展开；
- 新门禁套件：`shared-solver/check-counterfactual-repair.js`（G24-A 至 G24-F）。

非目标：
- 严禁重新开启旧 `failure-intent ranking`（不按 intentScore 重新排序已有候选）；
- 严禁使用加权评分（scalar intent score）或 bandit/UCB；
- 不修改 PR-5.24d 的假说调度、独立探测试算与状态身份契约；
- 不增加全局预算（30s / 50k / 2048MB 安全熔断保持不变）；
- 严禁人工 route hint 或 OnlyUp 专属特殊硬编码；
- 严禁扩大 candidateLimit / backtrackCandidateLimit。

## 初始设计

1. **机会扫描与 Trade-off 提取**：
   在回溯锚点处，从起始候选出发枚举前瞻动作，评估 `before` 到 `after` 的数值变化。过滤纯损失状态，仅提取产生明确能力增益（Gain）的投资机会。
2. **Pareto 剪枝与类别分散**：
   在 $(gain, cost)$ 空间计算 Pareto 支配集。消除被完全支配的劣质机会，并在保留集中按增益类型选取最多 `backtrackCandidateLimit` 个代表。
3. **具象 Subgoal 合成**：
   为选中的机会构造具体的目标断言（例如 `floorId`、`minHero`、`equipmentIncludes` 或 `removedTiles`），附带允许该动作链的 `actionPolicy`。严禁生成空目标 `{ type: "adaptiveResourceIntent" }`。
4. **规范 DP 实测物化（Realization）**：
   在父 wave 预算内，以 200 exp / 2000 ms 作为 realization probe，通过 `runSegmentAgainstFrontier()` 真实执行该子目标段，将产出的新状态作为新的 repaired frontier 输入后续回放与调度器。

| **G24-B** 投资解锁下游段 | 合成 fixture | 正常省血历史全无进展；由投资 intent 产出的前史在下游成功打通门禁，达成顶层 `FOUND === true` |

| **G24-D** Pareto 无权重支配 | 单元断言 | 机会 A（cost 20, atk +2）支配 B（cost 40, atk +2），C（cost 30, atk +4）不被支配；断言仅保留 A 与 C，严禁标量加权排序 |
| **G24-E** 非纯属性通用类型 | 合成 fixture | 验证装备获取（equip）或开门/钥匙/路径解锁（path unlock）场景，证明机制非“专职刷怪” |
| **G24-F** 有界性与不递归 | 架构断言 | intent 数量 $\le$ backtrackCandidateLimit，candidateLimit 未膨胀，单深度仅执行 1 轮 counterfactual 展开 |
