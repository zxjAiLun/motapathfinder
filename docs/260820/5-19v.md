## 本轮范围（observation-only）

- root charge record 补充 `prerequisiteId` 与 `parentDependencyId`；identity 继续用 floorId/enemyId/x/y。
- 纯 helper `classifyPreHierarchyRootRetryNovelty(rootCalls)`：只比较 `firstHierarchyActivationOccurred=false` 的 root calls，按 prerequisiteId + 完整 boundary identity 分组；每个 retry 与同组**所有**更早 call 比较（不只最近一次）。
- 指标合同（required metrics）：
  - 越高越好：attackMargin、survivalMargin、sourceTerminalProgressScore
  - 越低越好：damage
  - false→true 改善：reachableAtCompileTime
  - 只记录为 `contextDifferenceKeys`、不能冒充指标改善：sourceDepth、sourceFloor、beforeStage、stageGoal、compiledCandidateRank/Count
- 每个 comparison 输出：improvedFields / regressedFields / equalFields / missingFields / contextDifferenceKeys / exactSemanticEqual。
- 分类：FIRST-SEEN、EXACT-SEMANTIC-RETRY、METRIC-TIE-CONTEXT-ONLY、PRIOR-ATTEMPT-DOMINATES、CURRENT-ATTEMPT-IMPROVES、MIXED-TRADEOFF、EVIDENCE-INCOMPLETE（只有 required metric 缺失时才用 EVIDENCE-INCOMPLETE）。
- search-end 生成 `stats.rootRetryNoveltyAttribution`（schema v1）：`preChargeComparisons` 严禁 productive/directSatisfied/satisfied/materialized/continuation outcome 等事后字段；`postSearchEvaluation` 单独连接既有 label。
- offline verdict 四类：
  - `TRACE-LOCAL-NONPRODUCTIVE-DOMINATED-RETRY-OBSERVED`（仅说明当前 trace 存在未来 shadow 候选，不授权 suppression）
  - `PRODUCTIVE-ROOT-WOULD-BE-FLAGGED`
  - `NO-PRECHARGE-NONIMPROVING-RETRY`
  - `EVIDENCE-INCOMPLETE`

## Synthetic gates（checker 内，纯 helper）

- exact retry（semantic 全同）→ EXACT-SEMANTIC-RETRY
- metric tie + context only → METRIC-TIE-CONTEXT-ONLY
- strict dominance（更早 attempt 全指标 ≥ 且至少一个严格更好）→ PRIOR-ATTEMPT-DOMINATES
- improvement → CURRENT-ATTEMPT-IMPROVES
- mixed tradeoff → MIXED-TRADEOFF
- missing metric → EVIDENCE-INCOMPLETE
- FIRST-SEEN
