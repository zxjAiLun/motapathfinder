### Stage 合同

```text
supported stages 有序：attack-blocked < lethal < viable
unsupported 不参与有序比较 → INCOMPARABLE-UNSUPPORTED

attack-blocked 同阶段：只要求 attackMargin
lethal/viable 同阶段：要求 attackMargin、damage、survivalMargin
通用指标（所有可比较阶段）：sourceTerminalProgressScore、reachableAtCompileTime

damage/survivalMargin 在任一 side 为 attack-blocked 时记录为 notApplicableMetrics，
不得进入 missingFields / unexpectedMissingMetrics
```

### 每 pair 输出字段

```text
earlierStage / currentStage / stageRelation
applicableMetrics / notApplicableMetrics / unexpectedMissingMetrics
improvedFields / regressedFields / equalFields
contextDifferenceKeys / exactObservableVectorEqual
```

### Pairwise classification（固定 9 类）

```text
EXACT-OBSERVABLE-RETRY
STAGE-PROGRESS
STAGE-REGRESSION
SAME-STAGE-PRIOR-DOMINATES
SAME-STAGE-CURRENT-IMPROVES
SAME-STAGE-METRIC-TIE-CONTEXT-ONLY
SAME-STAGE-MIXED-TRADEOFF
INCOMPARABLE-UNSUPPORTED
UNEXPECTED-MISSING-APPLICABLE-METRIC
```

判定顺序：exact 优先 → 任一 side 为 unsupported 则 incomparable → 跨 supported stage 先按 `stageRelation` 分类（progress / regression）→ 同阶段才比较该阶段的 applicable metrics（applicable 但缺失即 `UNEXPECTED-MISSING-APPLICABLE-METRIC`）。

### Search-end 输出与 offline verdict

`stats.rootRetryMetricApplicabilityAttribution`，schema `motapathfinder.strategic-root-retry-metric-applicability-attribution.v1`。

- `preChargeComparisons` 严禁 post-hoc label（productive/directSatisfied/satisfied/materialized/continuation）。
- `postSearchEvaluation` 独立连接 productive/directSatisfied；每条 non-improving comparison 必须链接到唯一且 `productive` 为 boolean 的条目，否则进 `missingEvaluationCallOrdinals` 并 fail-closed。
- offline verdict 固定四类，优先级如下：

```text
PRODUCTIVE-ROOT-WOULD-BE-FLAGGED
  > STAGE-CONDITIONAL-EVIDENCE-INCOMPLETE
  > TRACE-LOCAL-STAGE-CONDITIONAL-NONIMPROVING-RETRY-OBSERVED
  > NO-STAGE-CONDITIONAL-NONIMPROVING-RETRY
```

- 四组 ordinals 在**每个** verdict 分支都反映真实检测：`productiveFlaggedCallOrdinals`、`nonProductiveFlaggedCallOrdinals`、`incompleteCallOrdinals`、`missingEvaluationCallOrdinals`。

## Output contract

```text

  rootCallCount / repeatGroupCount
```
